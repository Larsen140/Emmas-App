# Emmas Planner

Einkaufsliste, Angebote, Termine, To-dos – als Web-App fürs iPhone und iPad.

**App:** https://larsen140.github.io/Emmas-App/

- Läuft komplett im Browser. Liste, Termine und To-dos bleiben auf Emmas Gerät.
- Angebote kommen aus dem privaten Repo `emmas-app-daten` (jeden Montag um 6 Uhr und sofort bei neuen Produkten).
- Verbindung: In der App unter **Optionen → Verbindung für Angebote** einmal den Token eingeben.

Auf dem iPhone: Link in Safari öffnen → Teilen → **Zum Home-Bildschirm**.
